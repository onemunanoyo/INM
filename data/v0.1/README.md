# INM v0.1 working dataset

> **Status: working draft — not a frozen release.**

This directory contains the canonical-schema working set for v0.1. The current
contents are human-reviewed candidates promoted from `data/candidates/`. The
set may still change until a v0.1 release/tag is created.

Current item counts:

- `character.jsonl`: 72
- `structure.jsonl`: 46
- `fake_quote.jsonl`: 0
- `quote_completion.jsonl`: 28
- **total: 146**

`fake_quote.jsonl` remains empty because fake-quote collision checking is not
yet complete. Human approval alone is not sufficient for promotion of a fake
item.

## Promotion rule

The current canonical set is generated by `scripts/promote_v01.py`. The script
uses an explicit allow-list of reviewed candidate files, requires every source
row to be `accepted_candidate`, requires at least one verified source ID, and
asserts the expected row count for every block.

Canonical rows retain `origin_candidate_id` for auditability.

Once v0.1 is formally released, the release item set should be treated as
immutable. Later additions belong to a later benchmark version.
